## Findings and R1 resolution

1. **Causal claims exceeded the experiment.** A stage-1 pass cannot isolate endpoint chasing because horizon cost, progress and keyframing change together. A stage-2 failure cannot uniquely establish learned-dynamics error, particularly with different stage budgets, censoring and closed-loop paths. Passing a demonstration grasp index without a scored grasp does not establish accurate pose tracking or identify object blindness as the cause. The coordinator's R1 protocol edits narrow these statements and explicitly interpret the existing reading keys as index/stage heuristics. This resolves the scientific wording finding without changing numeric gates.

2. **Stationary robot state does not establish harmless waiting removal.** Object and contact settling may continue while the selected robot state remains nearly unchanged. R1 now states this risk explicitly. No keyframe parameter change is requested before this bounded test.

3. **Descriptive conclusiveness was inconsistent with incomplete cohorts.** The original `tracking_ceiling_gate` and `tracking_gate` assign `readings.conclusive = passed or conclusive`. A numeric gate may pass with missing attempts counted as zero, as the protocol permits, but its descriptive readings are only conclusive when all planned attempts count with valid provenance (and exact rollouts for the ceiling). For example, two counted ceiling grasps plus two missing attempts can satisfy the numeric gate without completing the four-reset diagnostic cohort. Preserve the numeric pass/fail rule and conditional stage authorization; set the descriptive flag to its complete-cohort predicate. This is a reporting fix, not a threshold change. Final blocker clearing is contingent on the assigned code fix and focused missing-attempt regressions.
