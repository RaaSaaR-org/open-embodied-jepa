Every unordered sibling pair has measured full-frame RGB RMS, actual-action RMS and state RMS. A pair is informative only if full-frame RGB RMS >= 1/255 AND action RMS > 1e-8. The threshold is an operational image-divergence screen, not evidence that apple pixels or contacts are visible. Report every pair, including below-threshold cases, exact ties, and root/phase/split counts. Do not replace missing roots or select successful branches.

Let C[i,j] be the model's image-goal distance from the prediction under sibling i's actions to measured endpoint j. For pair i,j, two directed goal-ranking decisions compare C[i,i] with C[j,i], and C[j,j] with C[i,j]. A correct strict lower cost scores1, incorrect0, and ties0.5. A tie means abs(a-b) <= 1e-10 + 1e-6*max(abs(a),abs(b)); ties remain in the denominator. Pair ranking is the mean of both decisions. Persistence forecasts give the same prediction for both actions, hence rank0.5 by construction, and their actual visual endpoint MSE is also reported.

Separately, denormalize the predicted RGB grid using the checkpoint's frozen scales. For each informative pair, own error is the mean of raw-grid MSE(pred_i,end_i) and MSE(pred_j,end_j); wrong-action error swaps predictions. Report normalized proprio errors separately (scales differ between models, so those errors are not directly comparable across checkpoints). Average informative pairs within each root; average roots equally. Visual error reduction R = 1 - mean(root own error)/mean(root wrong error).
